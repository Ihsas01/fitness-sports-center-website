# Fitness Sports Center Website

A modern, responsive website for a fitness sports center built with React and Vite.

## Live Demo

Check out the live demo: [https://fitness-sports-center-website.vercel.app/](https://fitness-sports-center-website.vercel.app/)

## Tech Stack

- **React** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling

## Project Structure

```
src/
├── components/     # React components (Navbar, Hero, Services, etc.)
├── images/         # Image assets
├── App.jsx         # Main App component
├── index.css       # Global styles
└── main.jsx        # Entry point
```

## Getting Started

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

## Features

- Responsive design
- Modern UI with Tailwind CSS
- Fast development with Vite
- Sections: Home, About, Services, Pricing, Trainers, Contact
